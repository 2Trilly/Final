# 2Trill Website

This repository contains the supplied 2Trill website as a standalone HTML page.

## Files

- `index.html` — the original HTML supplied for this rebuild. It includes its image assets inline as data URLs.
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing.

## Publish with GitHub Pages

1. Create a new, empty GitHub repository.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root.
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Open the Pages URL after deployment finishes.

## Important

The supplied `index.html` is copied without changing its visible wording, markup, styles, or scripts. Images are embedded in the HTML, so no separate image folder or asset manifest is required.
